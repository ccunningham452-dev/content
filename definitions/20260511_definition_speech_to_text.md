# Speech to Text

## Definition

Speech to text is the process of converting spoken audio into written text. In
software projects, this is usually done with automatic speech recognition models
that accept an audio file or stream and return a transcript.

## Context and Usage

Speech to text is used for meeting notes, captions, podcast workflows, customer
support analysis, searchable video archives, and accessibility tooling. Modern
speech to text APIs often support language hints, prompt context, timestamps,
and multiple output formats so teams can turn raw recordings into structured
data for downstream applications.
